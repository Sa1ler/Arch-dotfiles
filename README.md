## 📦 Что внутри

- **🌿 Hyprland** — плавный тайловый композитор Wayland.
- **🖥️ Waybar** — настраиваемая панель с модулями.
- **📂 Rofi** — лаунчер и переключатель окон.
- **🖼️ Ghostty** — терминал с GPU-рендерингом.
- **📄 Neovim** — редактор с предустановленной LSP-конфигурацией.

- **➕ И многое другое...**
